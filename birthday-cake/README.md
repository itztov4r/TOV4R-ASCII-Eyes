# A Little Wish — ASCII Birthday Cake

An independent, mobile-friendly birthday greeting inspired by [@jin_22ee's generative ASCII cake reel](https://www.instagram.com/reel/DfZaM1FJ9nm/).

**Live website:** https://itztov4r.github.io/TOV4R-ASCII-Eyes/birthday-cake/

## Features

- Interactive 3D-looking birthday cake rendered entirely from ASCII characters on Canvas.
- Glowing candles, slow rotational movement, twinkling stars and particle confetti.
- Add a recipient's name, make a wish, blow out the candles, replay and share a personalized URL (`?to=Name`).
- Responsive design for phones and desktops, accessible buttons and reduced-motion support.
- Static HTML, CSS and JavaScript; no install or server required.

## Project files

- index.html: page content and controls.
- style.css: theme, typography, mobile layout and decorations.
- script.js: deterministic ASCII point cloud and interactions.

This is an original interpretation of the birthday ASCII art concept, not an extraction of the creator's source code or exact video frames.
